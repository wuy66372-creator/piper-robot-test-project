# GUMI 后台模型切换

刷新 GUMI，选择 0.8B、2B 或 4B，然后点击“加载所选模型”。网页显示后台实际加载的模型和加载状态。等待“模型和 LoRA 已加载”，启用浏览器前视相机，再点击“恢复控制”，即可预览或启动所选模型的实机推理。

切换会暂停控制、结束当前模型运行，等待正在进行的推理结束，检查本机权重后释放旧模型并加载对应基座和官方实机 LoRA。仅停止本地模型管理工具记录且核对身份的进程；端口被其他进程占用时拒绝启动。加载期间拒绝新推理、手动命令和恢复控制。模型与所选 LoRA 不匹配时拒绝推理；加载完成不会自动执行动作。

0.8B、2B、4B 共用上游 v3 提示词、双图输入、实机 token 映射和每步 20 mm 控制。2B sim LoRA 不作为真机选项。

2026-10-13 已通过 GUMI 的切换接口实际加载 4B 和 0.8B，并通过各自两组官方双图样例、每组重复两次的离线推理检查。4B 显存约 10.3 GB，0.8B 约 3.0 GB；这些是模型加载和图像推理验证，未执行机械臂动作。结果见 `../results/show_harness/models/20261013-173145-qwen3_5_4b.json` 和 `../results/show_harness/models/20261013-173226-qwen3_5_0_8b.json`。
